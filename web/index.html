    Commissioning the line

    The product is deployed. Jenkins is provisioned. The steps marked Owner need the owner's Clever Cloud account. Then the first crate rides the belt.

      Why the line waits

      Jenkins on Clever Cloud signs people in with their Clever Cloud account (SSO). The API token the factory floor reads with, and the Clever token the pipeline deploys with, can only be created by that person. Nothing is shared with the browser: both tokens stay on the server side.

      Until then, play a sample run to see how a build moves through the four stations.
